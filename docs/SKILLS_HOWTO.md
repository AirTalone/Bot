# Как пользоваться скиллами (простыми словами)

Скиллы уже лежат в репозитории: `.agents/skills/` (и ссылка `.cursor/skills/`).
Cursor подхватывает их сам. Тебе не нужно «включать» каждый раз вручную.

## Каждый день

1. Открой этот проект в Cursor.
2. Напиши задачу обычным русским, например:  
   `Добавь напоминание админу, если заявка висит больше часа. С тестами.`
3. Если задача большая — добавь:  
   `Разбей в DAG через dag-task-runner, models из .cursor/models-vpn.json`
4. Перед мержем рискованного PR:  
   `Сделай parallel-code-review по текущему diff`
5. Перед боевым запуском (редко):  
   `Полный security-audit, отчёт положи вне git`

## Что за чем

| Ты хочешь | Что сказать |
| --- | --- |
| Новая фича бота | Обычный запрос + «с тестами» |
| Экономить токены на большой задаче | «Разбей в DAG… models-vpn.json» |
| Починить баг | «systematic-debugging: …» |
| Проверить безопасность PR | «parallel-code-review» или «auditing-security» |
| Жёсткий аудит перед продом | «security-audit» (Cloudflare) |
| Docker / CI | «добавь docker» / «настрой CI» — подтянутся `adding-docker` / `setting-up-ci` |

## Models map

Файл `.cursor/models-vpn.json`:

- `HIGH` → сложная логика (статусы, панель, security)
- `MED` → обычный код
- `LOW` → мелочь / тексты / README

Имена моделей сверь со своим пикером Cursor. Если Auto Router на тарифе доступен — `LOW`/`MED` можно оставить на Auto.

## Обновление скиллов

```bash
npx skills update -y
```

Список и хеши — в `skills-lock.json`.

## Важно

- Не гоняй Cloudflare `security-audit` на каждую мелочь.
- Не ставь десятки новых скиллов без нужды: начни с того, что уже в репо.
- Доменная логика VPN-оплаты описана в `vpn-bot-playbook` и `docs/PRODUCT_ROADMAP.md`.
